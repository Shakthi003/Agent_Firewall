# Test matrix

One place that maps each security property to the tests that prove it. Names are the test function names, so `uv run pytest -k <name>` runs one. Counts and results are not repeated here; run `uv run pytest` for the current state. Acceptance criteria numbers refer to [acceptance-criteria.md](acceptance-criteria.md).

| Property | What is checked | Tests (file) |
| -- | -- | -- |
| Unauthorized access | A missing, unknown, expired or disabled key is denied and audited | `tests/security/test_gateway_security.py` (`test_each_request_is_authenticated_on_its_own`, `test_a_claim_without_a_credential_is_a_denied_spoofing_attempt`); `tests/unit/test_identity_registry.py` |
| Spoofed identity | A claimed agent name or role never changes who is calling; conflicting claims are logged as spoofing | `test_gateway_security.py` (`test_scenario_f_a_wrong_agent_name_never_changes_the_identity`, `test_a_conflicting_identity_claim_is_logged_as_a_spoofing_attempt`, `test_identity_fields_are_not_forwarded_downstream`, `test_an_identity_claim_in_request_meta_is_ignored_and_logged`); `test_policy_enforcement.py` (`test_a_claimed_role_or_agent_name_cannot_change_the_decision`) |
| Cross-agent access | A tool not granted to the role is denied; one agent's key cannot act as another; one agent cannot spend another's approval | `test_gateway_security.py` (`test_scenario_e_a_registered_tool_not_granted_to_the_role_is_denied`, `test_a_valid_key_for_one_agent_cannot_be_used_to_act_as_another`); `test_approval.py` (`test_another_agent_cannot_spend_an_approval`) |
| Unknown tools | A tool outside the approved registry is denied; a tool the server offers but the registry omits is unreachable | `test_gateway_security.py` (`test_scenario_g_unknown_tool_is_denied`, `test_a_tool_the_server_offers_but_the_registry_omits_is_unreachable`, `test_the_gateway_refuses_to_start_if_an_approved_tool_is_missing_downstream`); `tests/unit/test_tool_registry.py` |
| Malformed arguments | Wrong, missing or extra arguments are refused before reaching a server; the grant is checked first so nothing leaks about the schema | `test_gateway_security.py` (`test_grant_is_checked_before_arguments_so_nothing_leaks_about_the_schema`); `tests/integration/test_gateway.py` |
| Destructive operations | Deleting a production resource and disabling monitoring are blocked; spelling tricks do not turn prod into dev | `test_policy_enforcement.py` (`test_scenario_b_delete_prod_resource_is_blocked`, `test_scenario_b_the_resource_still_exists_afterwards`, `test_spelling_tricks_cannot_turn_a_prod_call_into_a_dev_call`, `test_the_protected_branch_rules_through_the_gateway`) |
| Secrets access | No role and no scope can read secrets | `test_policy_enforcement.py` (`test_scenario_c_demo_run_secrets_are_blocked_by_policy`, `test_scenario_c_no_role_and_no_scope_can_read_secrets`) |
| Sensitive export | A large invoice export pauses; any other table is blocked | `test_policy_enforcement.py` (`test_scenario_d_large_export_needs_approval`, `test_scenario_d_payroll_export_is_blocked`, `test_the_list_and_export_boundaries_through_the_gateway`) |
| All planned unsafe calls | The 12 planned unsafe calls are stopped and none reaches a server | `test_policy_enforcement.py` (`test_all_twelve_unsafe_calls_are_stopped_and_none_reaches_a_server`); `tests/unit/test_baseline.py` (the same calls succeed unprotected) |
| Allowed calls still work | Allowed matrix rows reach the right server and return its result | `test_policy_enforcement.py` (`test_allowed_calls_reach_the_right_server_and_return_its_result`, `test_only_allowed_matrix_rows_reach_a_downstream_server`, `test_the_5000_boundary_through_the_gateway`) |
| Approval flow | Paused call returns pending; exact request runs once after approval; changed arguments, replays, expiry, other tool, self-approval and rejected requests never run | `tests/security/test_approval.py` (all 32 tests; for example `test_a_retry_with_changed_arguments_is_rejected_and_never_runs`, `test_a_second_use_of_the_same_approval_is_rejected`, `test_an_expired_approval_is_rejected`, `test_an_agent_cannot_approve_its_own_request_through_the_gateway`, `test_policy_is_evaluated_again_at_execution`) |
| Gateway / policy failure | A policy fault or broken rate limiter blocks even read-only calls; the gateway keeps serving; it does not start on a bad policy | `test_policy_enforcement.py` (`test_a_policy_fault_blocks_even_read_only_calls`, `test_a_broken_rate_limiter_fails_closed_for_read_only_calls`, `test_a_policy_fault_does_not_stop_the_gateway_answering_the_next_call`, `test_the_gateway_does_not_start_on_a_bad_policy_file`) |
| Audit unavailable | A call is not forwarded when the audit store cannot be written | `tests/security/test_audit.py` (`test_a_call_is_not_forwarded_when_the_audit_store_is_unavailable`) |
| Audit completeness and redaction | Every protected call has one complete stored event; no secrets or argument values are stored; results are not stored | `test_audit.py` (`test_every_protected_call_in_the_scenario_suite_has_one_complete_stored_event`, `test_no_canary_value_reaches_the_stored_log`, `test_tool_results_are_not_stored_in_the_log`, `test_identity_claims_are_not_stored_only_their_field_names`) |
| Audit tamper evidence | An edit or delete after the fact is detected | `test_audit.py` (`test_a_real_run_verifies_and_any_later_edit_or_delete_is_detected`); `tests/security/test_dashboard_api.py` (`test_verify_reports_intact_then_broken`) |
| Rate limiting | The burst limit is per agent and applies before policy | `test_policy_enforcement.py` (`test_the_11th_call_in_a_burst_is_refused_and_never_forwarded`, `test_the_rate_limit_is_per_agent_not_shared`) |
| Concurrency | Parallel denied or allowed calls are each decided and audited once; an approval spent by many callers runs exactly once | `tests/security/test_robustness.py` (`test_an_approval_spent_by_many_callers_at_once_runs_exactly_once`, `test_a_mixed_burst_is_decided_per_call`, `test_many_denied_calls_at_once_never_reach_a_server`) |
| Timeouts and downstream errors | A timed-out or crashed approved call is spent and cannot run twice; the gateway keeps serving; errors are audited | `test_robustness.py` (`test_an_approved_call_that_times_out_is_spent_and_cannot_run_twice`, `test_an_approved_call_whose_server_crashes_is_spent_and_cannot_run_twice`, `test_the_gateway_keeps_serving_after_a_timeout`, `test_a_downstream_error_is_audited_and_the_chain_stays_intact`) |
| Duplicate requests | A duplicate paused request is the same approval; the same invoice cannot be paid twice | `test_robustness.py` (`test_a_duplicate_paused_request_is_the_same_approval_not_a_second_one`, `test_paying_the_same_invoice_twice_is_refused_by_the_server`) |
| Network boundary | Agents reach only the gateway, not servers, database or approver API (needs Docker) | `tests/integration/test_network_isolation.py` |
| Behaviour detection | Each rule fires on its simulated attack, stays quiet on normal traffic, is repeatable; the known blind spot (slow scrape) is stated | `tests/security/test_detection.py` (`test_each_rule_fires_on_every_simulated_episode_of_its_attack`, `test_no_rule_fires_on_any_normal_session`, `test_the_slow_scrape_is_a_known_blind_spot_of_the_rules`, `test_scenario_d_a_bulk_export_request_is_flagged`) |
| Detection cannot change decisions | A maximum anomaly score changes nothing; a crashing monitor stops nothing; nothing in the enforcement path imports the detectors | `test_detection.py` (`test_a_maximum_anomaly_score_does_not_change_what_the_gateway_decides`, `test_a_crashing_monitor_does_not_stop_the_call_or_the_audit_record`, `test_nothing_in_the_enforcement_path_imports_the_detectors`) |
| Investigation is advisory | Every claim cites real events; the model cannot lower severity; the workflow can only read | `tests/security/test_investigation.py` (`test_invented_event_ids_are_rejected_not_displayed`, `test_the_model_cannot_lower_severity_below_the_deterministic_floor`, `test_the_evidence_source_has_no_write_path`, `test_investigation_code_imports_nothing_that_can_change_the_system`, `test_a_high_severity_run_changes_nothing_in_the_audit_log`) |
| Dashboard API | Every route needs the approver login; an agent key is refused; input errors and crashes return a request ID, not internals; policies and agents are read-only | `tests/security/test_dashboard_api.py` (`test_every_dashboard_route_needs_the_approver_login`, `test_invalid_input_is_a_422_with_a_request_id_and_no_internals`, `test_unhandled_error_returns_request_id_not_a_stack_trace`, `test_policies_and_agents_are_listed_read_only`) |
| Logging | Structured logs are one JSON object per line and never carry a stack trace | `tests/unit/test_logging_setup.py` |
| Secrets and dependencies | The secret scan catches a fake key; dependencies are audited | `tests/unit/test_secret_scan.py`; `uv run python -m scripts.security_scan` |

## Not covered

- No browser-driven test of the Approve and Reject buttons. The API tests cover the same endpoints.
- No load or soak test.
- The Docker network test needs Docker and is skipped without it.
